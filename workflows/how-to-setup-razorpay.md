# Setting up Razorpay
1. Go to https://dashboard.razorpay.com/ and create an account.
2. Complete your KYC to activate the account or generate Test Keys from Settings > API Keys > Generate Key.
3. Copy the 'Key Id' and 'Key Secret'.
4. In your code, replace the 'mock payment gateway' or dummy keys with your 'Key Id'.
5. Test the payment flow in Test Mode first before switching to Live Mode.
